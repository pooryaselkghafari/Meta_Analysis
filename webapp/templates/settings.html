AI settings

Three independently configurable AI slots, one per pipeline role. Each can use a model from any of three providers — Anthropic (Claude), OpenAI (GPT), or Google (Gemini) — with its own API key and its own effort/thinking level (trading response thoroughness for token/latency cost). Effort isn't supported by every model — the dropdown only offers levels the selected model actually accepts, and shows "not applicable" otherwise.

Keys are stored in plain text in ai_settings.json at the project root, for local use only — it's already excluded via .gitignore. Each slot keeps a separate key per provider, so switching a slot's model between providers won't overwrite the other provider's saved key. Leave a key field blank to keep the currently saved key for that provider.
